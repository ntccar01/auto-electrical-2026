# 驗證

## 不需外部套件的回歸測試

在專案根目錄執行（Node.js 22 或更新）：

```powershell
node --test tests/regression.test.cjs tests/gas.test.cjs
```

涵蓋兩單元完整／缺線／空配線評分、零分封存、新考試與重繳 ID、舊資料相容、姓名排除、起動控制與主電源故障，以及 GAS 的身分驗證、整批匯入、去重、核章鎖定、學期與證書簽章。

## 真實瀏覽器驗收

需要 Playwright Node 套件與已安裝的 Microsoft Edge。本專案不在背景下載或安裝瀏覽器。

```powershell
node tests/browser.cjs
```

若使用 Codex 隨附套件，可先設定：

```powershell
$env:NODE_PATH='C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules'
node tests/browser.cjs
```

browser.cjs 啟動隨機 localhost 連接埠、使用全新的隔離瀏覽器內容、以 TEST_A 等虛構資料操作，結束後關閉伺服器與瀏覽器。驗收包含配線、刪線、電表拖曳、OEM、考評、CSV／JSON 匯出、教師篩選／調分／核章、本機證書、雲端教師頁、學生證書分享連結／遮罩查驗／列印、平板觸控與手機版面。Google 服務在此由本機 mock 取代，不代表實際 Google OAuth 或資料已寫入雲端。

截圖與下載檔寫在 test-results/，已排除 Git。tests/helpers.cjs 與 gas-helpers.cjs 為測試環境，不應被部署為學生端或 Apps Script 生產檔。

## 仍需人工或線上驗證

- 真實平板的長按 ST、電表探棒操作手感與瀏覽器相容性。
- 本機學生證書頁、分享連結、遮罩欄位與列印版面已加入瀏覽器驗收；實際列印排版與 QR code 尚待後續。
- 新學生查驗部署的 Google Workspace 權限、教師分享連結、學生帳號跨裝置查驗及教師端仍受限的線上驗證。
- 2026-11-03 已以教師帳號實測既有雲端匯入、核章、發證與簽章查驗；新學生查驗部署尚未線上驗證。
- 起動電壓使用固定 12V 電源、理想配線／開關及 30Ω／2Ω／1.5Ω 教學電阻求節點電壓；180A 搖轉顯示仍為狀態示意，未建模電瓶內阻、反電動勢、接點動態與短路熔斷。完全浮接端點暫以 0V 參考顯示。

面試報告驗收：Node 測試涵蓋教師權限、學生同意、已核章篩選、簽章竄改與到期邊界；browser.cjs 操作教師產生報告連結、顯示未遮罩班級與成績及列印模式。Google 服務仍為 mock。

起動 C 軌：三題驗證未量測禁止維修、故障同時生效、修後功能確認與100分評分；瀏覽器驗證挑戰入口、維修表單、三題完整繳交。C-01 驗收練習與考評、固定探棒切換檔位、下游維修順序及修後新證據，程式定位探棒後由實際電表與記錄功能產生量測。C-02／03 以求解器配合測試輸入產生量測事件，探棒拖曳另有既有驗收。


起動動畫驗收涵蓋正常搖轉、放開 ST 停止、主電源故障時電磁開關吸合但齒輪靜止。兩單元考評模式驗收線路圖及教學參考值分頁。

起動安全量測涵蓋OFF時ST停用、鬆開回IG、斷開負極保留配線、帶電Ω檔顯示LIVE與錯誤紀錄、直接量電瓶兩極的阻擋，以及C-01先確認無電壓再量電阻。

台架練習驗收包含先拆離負極、正常及故障接點的手動推動電阻、通電壓降、帶電Ω檔阻擋、鬆開自動記錄、手機版面、原電路狀態保留及考評隱藏入口。

台架V2驗收新增真實計時的吸合／回位循環、B–M脈動電壓、ST–G開路與ST–M正常電阻、正常情境對照、釋放及取消操作後停止計時。

台架V3驗收新增高阻接點有限電阻、通電壓降、兩支路電流平衡、低阻正常對照、慢轉動畫、放開停止及情境網址載入。

台架V4驗收新增身分逐筆快照、UTC／台北時間、含BOM的CSV實際下載、公式字元處理、取消與確認清空、清空後繼續記錄、空清單按鈕停用。

起動電流方向驗收涵蓋正向／反向畫線、保險絲出口至電磁B、馬達及線圈搭鐵回流、正常吸合後吸入線圈停止流動及B–M開路後的回送狀態。確認電表讀值與原模型一致。

引導版面驗收量測1440px與390px視窗的提示／按鈕邊界，確認不重疊且無橫向溢出，並保存對照截圖。

喇叭C軌四題使用A卷真實登入、完整配線及按鈕驗收，確認登入不覆蓋複合故障、各階段功能、正常選項不足以通過、修復後正確診斷及證據可通過；並驗收回練習重設。
